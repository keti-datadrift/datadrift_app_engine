# [기술 백서] 학습 없는 잠재 공간 직교 정사영을 통한 멀티모달 속성 제어 기술

> **부제**: 피셔(R.A. Fisher)의 실험계획법에서 시작해 CLIP 잠재 공간의 기하학적 제어까지
> **작성일**: 2026년 10월 14일
> **문서 성격**: 개념적 직관(Level 1)부터 엄밀한 선형대수학·다변량 통계 유도(Level 2~5)를 포괄하는 이중 구조 기술 문서

---

## 1. 개요 (Executive Summary)

현대 멀티모달 파운데이션 모델(CLIP, FashionSigLIP 등)은 이미지와 텍스트를 고차원 잠재 공간(\(\mathbb{R}^{768}\))의 단일 벡터로 사상합니다. 그러나 이 벡터는 형태, 색상, 텍스처, 배경, 조명 등이 비선형적으로 뒤엉킨 **'얽힌 표현(Entangled Representation)'**입니다. 이로 인해 "색상만 동일하고 형태는 자유로운 옷", "넥라인만 특정 형태인 옷"처럼 단일 속성에 특화된 정렬 및 군집화를 수행하기 어렵습니다.

본 기술은 **모델 재학습(Fine-tuning)이나 대규모 이미지 라벨링 없이**, 약 40개의 텍스트 프롬프트와 **선형 정사영(Linear Projection) 및 직교 여공간 차감(Orthogonal Complement Subtraction)**만을 활용해 특정 속성 공간을 완벽히 분리해내는 훈련 배제(Training-free) 잠재 공간 제어 방법론입니다.

## 2. [Level 1] 초등학생도 단번에 이해하는 비유와 원리

컴퓨터가 옷을 보고 처리하는 과정을 일상적인 사물과 비유로 쉽게 풀어봅니다.

```
[원래 상태: 비빔밥]        [text_r: 마법 색안경]      [remove_r: 지우개 기술]       [mix_r: 짬짜면 반반]
온갖 재료가 마구 섞여       원하는 속성(색상)만       방해꾼(무늬·모자)을 먼저     전체 형태 50% + 색상 50%
어떤 게 핵심인지 모름      돋보기처럼 또렷하게 봄     지우개로 지우고 색상 집중     최고의 균형 잡힌 벡터
```

### 1) 원래 컴퓨터는 옷을 어떻게 볼까요? (비빔밥 상태)

컴퓨터는 옷 사진을 보면 **768개의 숫자**로 요약해서 기억합니다. 그런데 이 숫자 속에는 **색깔, 줄무늬, 긴팔인지 반팔인지, 헐렁한지 딱 붙는지, 심지어 사진 뒤의 하얀 배경까지 몽땅 한 그릇에 섞인 '비빔밥'**처럼 엉켜 있습니다.
그래서 *"이 파란 셔츠랑 색깔이 똑같은 옷 찾아줘!"*라고 부탁하면, 엉뚱하게 단추 모양이나 셔츠 깃에 한눈이 팔려 엉뚱한 줄무늬 셔츠를 가져오기도 합니다.

### 2) 원하는 것만 쏙 골라보는 '마법 색안경' (`text_r`)

비빔밥에서 콩만 골라내려면 특수 안경이 필요합니다.
컴퓨터에게 "빨간 옷", "파란 옷", "하얀 옷" 같은 글자를 40개 읽힌 뒤, "옷"이라는 흔한 글자는 싹 날려버리고 **'진짜 색깔 차이'만 모아둔 16개의 마법 렌즈**를 만듭니다. 이 안경을 끼고 옷 사진을 쳐다보면 옷 모양은 흐릿해지고 **오직 색깔만 레이저처럼 또렷하게** 보입니다.

### 3) 방해꾼을 먼저 지우는 '지우개 기술' (`remove_r`)

옷에 커다란 호랑이 그림이 있거나 두꺼운 털 모자가 달려 있으면 색안경을 써도 눈이 어지럽습니다.
그래서 **지우개**를 씁니다. 색깔을 보기 전에 무늬, 모자, 소매 같은 방해 요소들을 지우개로 쓱쓱 지워버린 다음 색안경을 낍니다. 방해꾼이 없으니 **색깔 하나는 기가 막히게 잘 맞추지만, 원래 옷이 반팔이었는지 긴팔이었는지 모양을 좀 까먹는 단점**이 있습니다.

### 4) 짬짜면처럼 반반 섞기 (`mix_r`)

지우개로 다 지우자니 옷 모양을 잃어버리고, 그냥 두자니 색깔을 덜 맞춥니다. 그래서 **반반 피자(짬짜면)** 방식을 씁니다.
**"원래 옷 모습 50% + 색안경으로 본 모습 50%"**를 나란히 붙여서 새 카드를 만듭니다. 이렇게 하면 옷의 예쁜 실루엣도 살리면서, 내가 원하던 색상도 정확하게 찾아내는 가장 이상적인 결과를 얻습니다.

## 3. [Level 2] 시스템 입력과 출력 (I/O Architecture)

본 알고리즘은 **[준비 단계 \(\to\) 변환 단계 \(\to\) 검색/군집화 단계]**의 3단계 파이프라인으로 구성됩니다.

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ Phase 1. 속성 필터 기저(U) 제작 (준비 단계)                                             │
│  [Input]  속성 묘사 텍스트 문장 40개 ("a red top", "a navy shirt" ...)                  │
│     │                                                                                  │
│     ▼ (텍스트 인코더 -> 공통 평균 제거 -> SVD 차원 축약)                                 │
│  [Output] 선형 변환 행렬 U (768 × 16)                                                   │
└────────────────────────────────────────┬───────────────────────────────────────────────┘
                                         │
                                         ▼
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ Phase 2. 카탈로그 이미지 벡터 변환 (인덱싱 단계)                                         │
│  [Input]  상품 이미지들의 원본 768차원 임베딩 z, 그리고 변환 행렬 U                     │
│     │                                                                                  │
│     ▼ (선형 행렬곱 z @ U -> L2 정규화)                                                  │
│  [Output] 16차원 정규화 속성 좌표 c (또는 784차원 믹스 벡터)                             │
└────────────────────────────────────────┬───────────────────────────────────────────────┘
                                         │
                                         ▼
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ Phase 3. 조건부 검색 및 군집화 (서빙 단계)                                               │
│  [Input]  기준 상품의 변환 벡터 c_query, 카탈로그 변환 벡터들 {c_i}                      │
│     │                                                                                  │
│     ▼ (16차원 벡터 간 코사인 유사도 c_query · c_i 계산 및 정렬)                          │
│  [Output] 다른 잡음(형태/배경)이 배제되고 타깃 속성이 완벽히 일치하는 Top-K 추천 상품 군집│
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 상세 I/O 명세표

| 단계 | 처리 모듈 | 입력 (Input) | 출력 (Output) | 비고 |
|---|---|---|---|---|
| **Phase 1** | `subspace_basis()` | 텍스트 문장 리스트 \(K\)개 (\(K \approx 10 \sim 40\)) | 직교 기저 행렬 \(\mathbf{U} \in \mathbb{R}^{768 \times R}\) | 역전파 없음, 0.01초 내 연산 완료 |
| **Phase 2-A** | `project()` (`text_r`) | 이미지 벡터 \(\mathbf{z} \in \mathbb{R}^{768}\), 기저 \(\mathbf{U}\) | \(R\)차원 단위 속성 벡터 \(\mathbf{c} \in \mathbb{R}^R\) (\(R \le 16\)) | 원본 대비 약 \(48\)배 차원 압축 |
| **Phase 2-B** | `remove_subspace()` (`remove_r`) | 이미지 벡터 \(\mathbf{z}\), 비타깃 기저 \(\mathbf{U}_{\text{other}}\), 타깃 기저 \(\mathbf{U}_{\text{target}}\) | 비타깃이 소거된 \(R\)차원 단위 속성 벡터 \(\mathbf{c}_{\text{rem}} \in \mathbb{R}^R\) | 비타깃 간섭 차단 |
| **Phase 2-C** | `mix()` (`mix_r`) | 글로벌 벡터 \(\mathbf{z}\), 속성 벡터 \(\mathbf{c}\), 가중치 \(\alpha\) | \((768 + R)\)차원 하이브리드 단위 벡터 \(\mathbf{z}_{\text{mix}}\) | 전체 형태와 속성의 결합 |
| **Phase 3** | 코사인 랭킹 | 쿼리 벡터 \(\mathbf{q}\), DB 인덱스 행렬 \(\mathbf{C}\) | 유사도 상위 \(K\)개 상품 ID 및 군집 지표 | 밀리초(ms) 단위 검색 |

## 4. [Level 3] 수학적·선형대수학적 알고리즘 정밀 명세

이 절에서는 알고리즘의 선형대수학적 유도와 성질을 증명합니다.

### 4.1. 공통 정의 및 전제

- 이미지 인코더 \(f_I\)와 텍스트 인코더 \(f_T\)는 공유 잠재 공간 \(\mathbb{R}^D\) (\(D=768\))로 사상하는 정규화된 듀얼 타워 모델입니다.
- 이미지 임베딩: \(\mathbf{z} = \frac{f_I(x)}{\|f_I(x)\|_2} \in \mathbb{S}^{D-1}\)
- 정규화 함수: \(\mathcal{L}_2(\mathbf{v}) = \frac{\mathbf{v}}{\max(\|\mathbf{v}\|_2, \epsilon)}\)

### 4.2. 부분공간 기저 행렬 추출: `subspace_basis`

특정 속성 \(A\)를 기술하는 \(N\)개의 프롬프트 문장 임베딩 행렬을 \(\mathbf{T} \in \mathbb{R}^{N \times D}\)라 합니다.

1. **문맥 공통 성분 제거 (Mean Centering)**:

   \[
   \bar{\mathbf{t}} = \frac{1}{N} \sum_{i=1}^N \mathbf{T}_{i,:}, \quad \tilde{\mathbf{T}} = \mathbf{T} - \mathbf{1}_N \bar{\mathbf{t}}^T
   \]

   이 중심화 과정은 "a top", "a shirt" 등 모든 문장에 공통으로 등장하는 캐리어 토큰의 기저 벡터를 원점으로 평행이동시켜 상쇄합니다.

2. **특이값 분해 (SVD)**:

   \[
   \tilde{\mathbf{T}} = \mathbf{V} \mathbf{\Sigma} \mathbf{W}^T
   \]

   여기서 우측 특이벡터 행렬 \(\mathbf{W} \in \mathbb{R}^{D \times N}\)의 각 열은 프롬프트 분산이 극대화되는 직교 주성분 방향입니다.

3. **랭크 절단 (Rank Truncation)**:

   요청 랭크 \(R\)에 대해 \(\mathbf{U} = \mathbf{W}_{:, 1:R} \in \mathbb{R}^{D \times R}\)을 취합니다.

   \[
   \mathbf{U}^T \mathbf{U} = \mathbf{I}_R \quad (\text{Orthonormal Basis})
   \]

### 4.3. 선형 정사영 제어: `text_r`

이미지 임베딩 \(\mathbf{z}\)를 속성 부분공간으로 투영하고 단위 구 위로 정규화합니다.

\[
\mathbf{c}_{\text{text}} = \mathcal{L}_2(\mathbf{z} \mathbf{U}) \in \mathbb{S}^{R-1}
\]

두 이미지 \(\mathbf{z}_1, \mathbf{z}_2\)의 변환 좌표 내적 \(\mathbf{c}_1 \cdot \mathbf{c}_2\)는 고차원 768차원 공간 내에서 **두 벡터가 속성 부분공간 \(\text{span}(\mathbf{U})\) 위에 드리운 그림자 사이의 사잇각 코사인**과 정확히 같습니다.

### 4.4. 비타깃 부분공간 직교 여공간 사영: `remove_r`

목표 속성 외에 제거하고자 하는 \(M\)개의 비타깃 속성 프롬프트로부터 구축된 직교 기저를 \(\mathbf{U}_{\text{other}} \in \mathbb{R}^{D \times R_{\text{other}}}\)라 합니다.

1. **비타깃 정사영 성분**:

   \[
   \mathbf{p}_{\text{other}} = \mathbf{z} \mathbf{U}_{\text{other}} \mathbf{U}_{\text{other}}^T
   \]

2. **잔여 직교 벡터 도출**:

   \[
   \mathbf{z}' = \mathbf{z} - \mathbf{p}_{\text{other}} = \mathbf{z} (\mathbf{I}_D - \mathbf{U}_{\text{other}} \mathbf{U}_{\text{other}}^T) = \mathbf{z} \mathbf{P}_{\perp}
   \]

   여기서 \(\mathbf{P}_{\perp}\)는 비타깃 공간의 영공간(Nullspace)으로 사영하는 대칭 멱등 행렬(Symmetric Idempotent Matrix)입니다.

3. **타깃 기저 사영 및 합성 행렬**:

   \[
   \mathbf{c}_{\text{remove}} = \mathcal{L}_2(\mathbf{z}' \mathbf{U}_{\text{target}}) = \mathcal{L}_2\left(\mathbf{z} \underbrace{\mathbf{P}_{\perp} \mathbf{U}_{\text{target}}}_{\mathbf{M}_{\text{composite}}}\right)
   \]

   비타깃 제거 후 타깃 투영 과정은 런타임에 다단계 계산을 할 필요 없이, 미리 오프라인에서 계산된 단일 합성 행렬 \(\mathbf{M}_{\text{composite}} \in \mathbb{R}^{D \times R_{\text{target}}}\)을 곱하는 단 한 번의 선형 변환으로 축약됩니다.

### 4.5. 하이브리드 블록 벡터 합성: `mix_r`

기존 글로벌 유사도와 속성 특화 유사도를 볼록 결합(Convex Combination)하기 위해 두 정규화 벡터를 가중치 \(\alpha \in [0, 1]\)로 스케일링하여 결합(Concat)합니다.

\[
\mathbf{z}_{\text{mix}} = \begin{bmatrix} \sqrt{1 - \alpha} \cdot \mathbf{z} \\ \sqrt{\alpha} \cdot \mathbf{c}_{\text{attr}} \end{bmatrix} \in \mathbb{R}^{D + R}
\]

길이 보존:

\[
\|\mathbf{z}_{\text{mix}}\|_2^2 = (1 - \alpha) \|\mathbf{z}\|_2^2 + \alpha \|\mathbf{c}_{\text{attr}}\|_2^2 = (1 - \alpha)(1) + \alpha(1) = 1
\]

별도의 정규화 나눗셈 없이도 자동으로 단위 구 \(\mathbb{S}^{D+R-1}\) 표면에 위치합니다.

코사인 유사도의 선형 가중합 보존:

\[
\mathbf{z}_{\text{mix}}^{(1)} \cdot \mathbf{z}_{\text{mix}}^{(2)} = (1 - \alpha) \left(\mathbf{z}^{(1)} \cdot \mathbf{z}^{(2)}\right) + \alpha \left(\mathbf{c}_{\text{attr}}^{(1)} \cdot \mathbf{c}_{\text{attr}}^{(2)}\right) = (1 - \alpha) \cos_{\text{global}} + \alpha \cos_{\text{attr}}
\]

단일 벡터 내적 한 번으로 전역 시각 유사도와 타깃 속성 유사도의 \((1-\alpha) : \alpha\) 가중 결합이 수학적으로 오차 없이 계산됩니다.

## 5. [Level 4] 학술적 계보와 기존 연구 (Academic Lineage)

본 기법은 통계학의 기초 이론과 현대 딥러닝 표현 공학 연구들의 교차점에 위치합니다.

```
[1920s 피셔 통계학]               [2020s 딥러닝 표현 공학]
실험계획법 (DOE)      ────────►    프롬프트 템플릿 고정 (Confounder 통제)
분산분석 (ANOVA)      ────────►    Mean Centering + SVD (주효과 분산 추출)
공변량 분리 (ANCOVA)   ────────►    INLP 영공간 사영 (remove_r 선형 직교 차감)
```

### 5.1. 피셔(R.A. Fisher)의 실험계획법 및 공변량 분리와의 대응성

1920년대 로널드 피셔는 로담스테드 농업시험장에서 "토양 비옥도나 햇빛 같은 교란 요인 속에서 특정 비료의 효과만을 어떻게 순수하게 측정할 것인가?"를 연구하며 현대 통계학을 정립했습니다. 본 기술은 피셔의 통계 철학을 고차원 신경망 공간에 그대로 재현합니다.

1. **가외 변인 통제 (Blocking & Control)**:
   피셔는 비료 외의 조건을 동일하게 통제하기 위해 구획(Block)을 나눴습니다. 본 기술에서 `"a [속성] top"`이라는 **고정 템플릿(Carrier Template)**을 사용하여 문장 구조, 품목 명칭 등의 가외 변인을 통제한 것과 일치합니다.
2. **분산 분할 (ANOVA)**:
   전체 변동에서 처리 간 변동(Between Group)만을 취하듯, 프롬프트 행렬에서 전체 평균 \(\bar{\mathbf{t}}\)를 빼 공통 성분을 소거한 뒤 SVD 주성분 축을 취합니다.
3. **공변량 제거 (ANCOVA)와 `remove_r`**:
   피셔의 공분산분석(ANCOVA)이 반응 변수에서 통제되지 않은 공변량(토양 성분)의 선형 회귀 성분을 사전에 덜어내듯(Partial out), `remove_r`은 타깃 속성을 계산하기 전 비타깃 부분공간(\(\mathbf{U}_{\text{other}}\))을 **직교 정사영하여 공변량을 차감**합니다.

### 5.2. 현대 딥러닝 원천 연구 계보

1. **INLP (Iterative Nullspace Projection, ACL 2020)**
   Ravfogel et al., *Null It Out: Guarding Protected Attributes by Iterative Nullspace Projection*
   - 텍스트 임베딩에서 성별, 편향 등 원치 않는 속성을 선형 분류기로 찾고, 그 가중치 벡터의 영공간(Nullspace)으로 데이터를 연속 투영하여 편향을 완벽히 제거하는 기법을 확립했습니다. 본 문서의 `remove_subspace`는 INLP의 단일 닫힌 형식(Closed-form) 축약형입니다.
2. **StyleCLIP (ICCV 2021) & CLIP (ICML 2021)**
   Patashnik et al., *StyleCLIP: Text-Driven Manipulation of StyleGAN Imagery*
   Radford et al., *Learning Transferable Visual Models From Natural Language Supervision*
   - 텍스트 타워의 차이 벡터(\(\Delta \mathbf{t}\))가 이미지 잠재 공간의 의미적 제어 방향과 선형적으로 일치함을 최초로 대규모 입증했습니다.
3. **TCAV (ICML 2018) & Representation Engineering (2023)**
   Kim et al., *Interpretability Beyond Feature Attribution: Quantitative Testing with Concept Activation Vectors (TCAV)*
   Zou et al., *Representation Engineering: A Top-Down Approach to AI Transparency*
   - 복잡한 비선형 딥러닝 모델의 내부 표현을 인간이 인지할 수 있는 개념 벡터(Concept Vector)들의 선형 부분공간으로 분해하고 제어할 수 있음을 체계화했습니다.

### 6.2. 트레이드오프 분석 및 최적의 실무 방식

5개 속성 전체에 걸친 기법별 평균 성능 비교입니다.

```
[목표 순도 상승 vs 비타깃 보존 트레이드오프]

목표 순도 Δ
   ▲
+21%│                    ● remove_r16 (순도 최대, 비타깃 -19.0%p)
    │              ● mix_r16_a050 (균형 최적: 순도 +20.7%p, 비타깃 -8.5%p)
+18%│        ● mix_r16_a025 (손실 최소: 순도 +18.2%p, 비타깃 -4.8%p)
    │
+10%│  ● data_centroid (학습 라벨 평균 기반: +10.6%p, 텍스트 축보다 열세)
    └──────────────────────────────────────────────► 비타깃 보존율 (Jaccard@10)
     0.1               0.3               0.5
```

1. **목표 속성 극대화가 최우선인 경우 \(\to\) `remove_r16`**
   - 목표 순도를 최대 +21.3%p까지 끌어올립니다.
   - 다른 속성의 정보 손실(비타깃 평균 19.0%p 하락)이 동반되므로 단일 속성 전용 검색 필터로 적합합니다.
2. **실제 추천 시스템 및 서비스 배포 권장 \(\to\) `mix_r16_a050` (또는 `a025`)**
   - 목표 순도는 `remove`와 거의 대등하게 챙기면서(+20.7%p), 비타깃 손실은 절반 이하(-8.5%p)로 억제합니다.
   - 원본 이미지의 전반적인 조화(스타일, 아이템 종류)를 잃지 않는 가장 안전하고 실용적인 방식입니다.

### 6.3. 엔지니어링 실무 가이드 (Checklist)

- 프롬프트 템플릿을 고정합니다. `"a [속성] top"`처럼 공통 캐리어를 유지하고 품목 단어를 바꾸지 않습니다.
- 문장 수와 Rank를 맞춥니다. 프롬프트 그룹 수가 적으면 요청 랭크가 자동으로 클리핑되므로, 목표 랭크 이상의 범주와 변주 문장을 확보합니다. 최소 15~20개 이상을 권장합니다.
- 오프라인 연산 결과를 캐시합니다. 필터 행렬 \(\mathbf{U}\)와 카탈로그 변환 벡터 \(\mathbf{c}\)는 수집/배치 파이프라인에서 1회 계산 후 DuckDB, Parquet, Numpy 파일로 저장합니다. 런타임에는 실시간 SVD를 돌리지 않습니다.
- 다속성 결합은 블록 단위로 검색합니다. 복합 조건(예: 네이비 + 오버핏)은 각 속성 벡터를 \(\mathbf{c} = [\mathbf{c}_{\text{color}}, \mathbf{c}_{\text{fit}}]\)처럼 이어 붙여 32차원 단일 인덱스로 탐색합니다.
